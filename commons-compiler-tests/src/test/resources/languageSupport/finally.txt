# "finally" blocks, and statements that leave them. See "LanguageSupportTest" for the format.

=== finally block that returns overrides the return value of the try block
jls: f
janino: OK
public class P {
    static String m() { try { return "t"; } finally { return "f"; } }
    public static Object run() { return m(); }
}
