# Overload resolution, constants, conversions and string concatenation. See "LanguageSupportTest" for the format.

=== overload resolution: f(long) is preferred over f(Integer) for f(1)
jls: long
janino: OK
public class P {
    static String f(long x) { return "long"; }
    static String f(Integer x) { return "Integer"; }
    public static Object run() { return f(1); }
}

=== overload resolution: f(Object) is preferred over f(int...) for f(1)
jls: Object
janino: WRONG varargs
public class P {
    static String f(Object x) { return "Object"; }
    static String f(int... x) { return "varargs"; }
    public static Object run() { return f(1); }
}

jls: varargs
janino: OK
public class P {

=== overload of a final method
jls: A.f() P.f(int)
janino: OK
class A { public final String f() { return "A.f()"; } }
public class P extends A {
    public String f(int x) { return "P.f(int)"; }
    public static Object run() { return new P().f() + " " + new P().f(1); }
}

=== method with the signature of a private final method of the superclass
jls: PA
janino: OK
class A {
    private final String f() { return "A"; }
    String g() { return f(); }
}
public class P extends A {
    public String f() { return "P"; }
    public static Object run() { P p = new P(); return p.f() + p.g(); }
}

=== override of a non-final method of a class with final methods
jls: A.f P.g
janino: OK
class A {
    public final String f() { return "A.f"; }
    public String g() { return "A.g"; }
}
public class P extends A {
    public String g() { return "P.g"; }
    public static Object run() { A a = new P(); return a.f() + " " + a.g(); }
}
