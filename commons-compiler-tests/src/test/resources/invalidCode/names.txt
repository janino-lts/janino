# Invalid names, references and contexts. See "InvalidCodeTest" for the format.

=== unknown type
janino: REJECTED Cannot determine simple type name "Foo"
public class P {
    Foo x;
}

=== unknown member type
janino: REJECTED "java.util.Map" declares no member type "Foo"
public class P {
    java.util.Map.Foo x;
}

=== unknown package
janino: REJECTED Cannot determine simple type name "java"
public class P {
    java.foo.Bar x;
}

=== unknown variable
janino: REJECTED Expression "undefinedVariable" is not an rvalue
public class P {
    int f() { return undefinedVariable; }
}

=== unknown static field
janino: REJECTED "foo" is neither a method, a field, nor a member class of "java.lang.String"
recovery: INVALID InternalCompilerException
public class P {
    Object f() { return String.foo; }
}

=== unknown field of superclass
janino: REJECTED Class has no field "x"
recovery: INVALID InternalCompilerException
public class P {
    int f() { return super.x; }
}

=== unknown method of superclass
janino: REJECTED Class "java.lang.Object" has no method named "foo"
public class P {
    void f() { super.foo(); }
}

=== instance method invoked in static context
janino: REJECTED Instance method "default void P.g()" cannot be invoked in static context
recovery: INVALID InternalCompilerException

    void g() {}
    static void f() { g(); }
}

=== instance method invoked through class name
janino: REJECTED Instance method "length" cannot be invoked in static context
recovery: INVALID InternalCompilerException

=== instance field in static context
janino: REJECTED Expression "P" is not an rvalue

=== non-final local variable accessed from anonymous class
janino: REJECTED Cannot access non-final local variable "x" from inner class

        x = 2;
        return new Runnable() { public void run() { int y = x; } };
    }
}
